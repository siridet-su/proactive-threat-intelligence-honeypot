`json.JSONDecodeError` in `_decode_payload` and `_json_value`, but exact
`325d136…` did not import `json`. The affected database forms are:

- `analyst_feedback.predicted_ranking`, stored as JSON text for all 121
  retained rows;

- null, empty, malformed and legacy scalar values, which must fail safely.

- `production/api/monitor_web.py` feedback API;
- monitor snapshot construction and feedback filtering/rendering;
- current-prediction feedback summaries used by monitor/dashboard consumers.

recovery runtime diff from `325d136…` is exactly:
